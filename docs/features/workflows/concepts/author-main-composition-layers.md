# Author main composition layers

The author workflow has two composition boundaries within the `main` package. Both are necessary
and neither subsumes the other.

  package structure and its lazy workflow registry; use [author main nodes package
  initializer](author-main-nodes-package-initializer.md) when exploring the deterministic node
  registry and the subject modules that populate it

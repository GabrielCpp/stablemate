# Author review-epic-split prompt

The epic-split flow renders this template for its review turn, which validates whether the split epic skeletons generated by the split turn are correct and complete. It directs an independent high-power agent to verify that the skeleton list is dependency-ordered, covers the roadmap's journeys and release boundary without introducing horizontal layer phases, includes no non-goals, and leaves every epic as a bare skeleton with no prose, seeds, or stories. The expected response is a JSON object with `status` set to `approved`, `needs_rework`, or `blocked`, and a `notes` value describing any required repairs or owner decisions.

### status
- type: literal `approved`, `needs_rework`, or `blocked`
- required: true
- semantics: `approved` — skeleton list is correct and ready for validation; `needs_rework` — agent has identified repairs; `blocked` — a product decision is required
- verify: json_path(path="$.status", matches="^(approved|needs_rework|blocked)$")

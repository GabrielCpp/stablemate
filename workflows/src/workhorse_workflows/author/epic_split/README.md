# epic_split

The machine that splits one approved milestone into an ordered list of epic skeletons. Epic prose, seeds and stories are out of its reach.

## Map

- `flow.py`: the epic-split state machine and its rework and answer budgets.
- `nodes/`: the deterministic intake and output checks around the split turn.
- `schemas.py`: the context, replies and validation values of the epic-split flow.

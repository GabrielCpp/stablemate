# shared

What more than one author machine needs.

## Map

- `listing.py`: the open debt register as the block of text a prompt reads.
- `nodes/`: the author nodes two or more machines call, on their own blueprint.
- `paths.py`: where the author's artifacts live: the repo root and every derived epic, story and context path.
- `schemas/`: the typed replies and node returns the author machines share.
- `survey/`: the survey kit both surveyors share: the frozen unit list, finding records and their gates.

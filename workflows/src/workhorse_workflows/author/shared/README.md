# shared

What more than one author machine needs.

## Map

- `paths.py`: where the author's artifacts live: the repo root and every derived epic, story, backlog and context path.
- `roadmap.py`: which roadmap is the repo's one approved roadmap.
- `schemas/`: the typed replies and node returns the author machines share.
- `story_split_receipt.py`: the durable receipt that an epic's story topology passed semantic review, and whether it is still current.
- `survey/`: the survey kit both surveyors share: the frozen unit list, finding records and their gates.

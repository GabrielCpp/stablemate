# nodes

The nodes only the default author flow calls. The nodes several machines share live in `author/shared/nodes/`.

## Map

- `_blueprint.py`: the node registry every module here decorates against.
- `fill.py`: files the epics, story splits and stories on the run's work list from the ostler graph.
- `completion.py`: the milestone contract digest, the unfinished work rows, and the reader of the operator's gate answer.

# nodes

The nodes only the default author flow calls. The nodes several machines share live in `author/shared/nodes/`.

## Map

- `_blueprint.py`: the node registry every module here decorates against.
- `artifacts.py`: the whole-run gates on what a run wrote.
- `intake.py`: whether the approved roadmap owns one milestone, and its advance to authored.
- `planner.py`: which one authoring stage runs next, read from the artifacts on disk.
- `stories.py`: one story's mockup gate, and the operator's notes on it.

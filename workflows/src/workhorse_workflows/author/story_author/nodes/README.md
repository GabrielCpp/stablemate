# nodes

The deterministic nodes of the story-author machine.

## Map

- `_blueprint.py`: the node registry the story-author nodes decorate against.
- `feedback.py`: the operator's notes on the story being written.
- `mockup.py`: whether one story needs a visual mockup before it is written.
- `story.py`: resolving the named story, giving it its required sections, and the receipt of a passing audit.

# okf_book main

The python book flow, which writes one service book under `services/<name>/`, or `services/<repo>/<name>/` where the book lives in the artifacts folder.

A book reached by a screen surface whose package exists gets a breadth pass before the owner. One with no package starts with the owner, whose first lap writes the package, because the survey cannot list a book that does not exist. The pass lists the entry files the book names nowhere and writes one skeleton screen per entry file, eight per turn. A file handed once is never handed again. The notes of each turn sit under `<run_dir>/breadth/`. A turn that ends without a reply records nothing and waits on an operator gate that names its files. The answer sends the same batch to a new turn, which opens on the answer.

After the breadth pass, a reasons pass writes why each screen no decision names behaves as it does. It takes five screens per turn and writes each reason with the sources the check opens. A why that nothing written gives becomes a line of the book's `QUESTIONS.md`. A screen handed once is never handed again. The notes of each turn sit under `<run_dir>/reasons/`. A turn that ends without a reply waits on an operator gate that names its screens, and the answer sends the same batch again. A decisions listing that exits non-zero waits on an operator gate with the command, its exit code and its output, and the answer lists again.

Then the flow runs `check`, then `run`, then `missing`, then `verified` for each module, then renders and commits. The stamp file `verified` writes is inside the book's package, so the commit carries it. A refused stamp sends the owner another lap with what it printed, like a red `run`. A `missing` that lists a file on a book with a screen surface goes through the breadth pass again before the owner. On any other book it sends the owner another lap with the list, like a red `run`. Either waits for the operator after three laps. The operator's answer reaches the owner's next turn, and that lap is judged against the cap again.

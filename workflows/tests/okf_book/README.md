# okf_book

The tests for the `okf-book` workflow.

## Map

- `main/`: the tests of the okf-book flows, and the tally app they drive.
- `shared/`: the tests of the code more than one okf-book flow calls.
- `support.py`: what every okf-book test drives a flow with: the paddock fixture apps, git reads and an agent scripted by prompt.

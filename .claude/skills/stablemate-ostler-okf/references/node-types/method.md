# `method`

A callable on a [`concept`](concept.md) or a [`format`](format.md): a function or method whose
contract is worth recording. Reach for `method` when the unit is a code-level API someone
calls, not a surface someone uses.

## Identity

Section type under a `## Methods` heading (or a nested `### method: …`). **`literal_id`** — the
id is the method name, a code identifier, so `ostler fmt` keeps its case exactly as authored
rather than kebabbing it into a slug.

## Bullet keys

| key | required | what it does |
| --- | --- | --- |
| `sig` | no | the signature |
| `abstract` | no | `true` when it has no implementation here |
| `does` | no | **mints an obligation** |
| `raises` | no | **mints an obligation** — what it throws and when |
| `returns` | no | **mints an obligation** — what it gives back |
| `code` | no | link, **owns** its file |
| `verify` | no | a check |
| `fixture` | no | a fixture |
| `tests` | no | link — the test files covering it |

`does:` is **not nested** here, unlike on an endpoint or interaction: one bullet, one claim,
repeated. Plus the
[shared normative keys](../bullet-grammar.md#keys-that-are-normative-on-every-type).

## Relationships

Belongs to the concept or format whose file it sits in. `detail:` points at a
[`concept`](concept.md) — it is not in this type's declared list, but relation keys work on
every type.

## Minimal example

```bash
timeout 30 ostler scaffold method MintSlug --in docs/features/acme/concepts/slug-minting.md
```

```markdown
### MintSlug

- sig: MintSlug(url string) (string, error)
- does: returns a six-character slug unused by any live link
- raises: ErrSlugExhausted after 10 collisions in a row
- returns: the slug, lowercase alphanumeric
- code: internal/slug/mint.go::MintSlug
- verify: count(subject="live links sharing the returned slug", equals=1)
- tests: internal/slug/mint_test.go
```

## Doctor codes it can trip

`undeclared-obligation`, `weak-check`, `unparsed-check`, `compound-normative-bullet`,
`overlong-normative-bullet`, `dangling-code-ref`, `missing-code-symbol`. See
[../doctor-codes.md](../doctor-codes.md).

## When bullets are not enough

Bullets state this callable's contract. If a reader could call the wrong one — a legacy helper
and its replacement, each right in its own context — and still satisfy every claim on it, that
belongs in a [`concept`](concept.md), pointed at with `detail:`.

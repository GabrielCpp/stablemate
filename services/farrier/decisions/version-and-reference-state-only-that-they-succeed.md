`farrier version` prints the version of the installed distribution and `farrier config reference` prints the
documentation of the keys, which the library edits with each release. The book states neither text: both declarations
leave every line opaque, so the claim is the exit code. A key no config file has is refused with a message the book
does state (`farrier/farrier/config_reference.py::reference_text`).

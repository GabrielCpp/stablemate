The surface sets HOME to the sandbox's home folder, AGENT_REPO_DIR to the sandbox and AGENT_CLI to claude, so a
dry run reads no skill, config or run from the machine it happens to run on. The sandbox path is written
<sandbox> in everything printed, so the run directory a dry run names is the same text in every world.

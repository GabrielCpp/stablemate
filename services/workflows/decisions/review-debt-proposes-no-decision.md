The review-debt run ends after it writes `trends.md`. It no longer drafts a decision for a cluster of records. A decision lives in the book of the service it concerns, or in a product page when it spans services, and a person or an agent writes it by hand. The trends file is where a recurring cause shows, and the one who reads it decides whether the cause deserves a page.
